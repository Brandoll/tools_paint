Cómo usar y límites

Para pegar, elige «Copiar imagen» en la otra aplicación y pulsa Pegar imagen aquí. El navegador puede pedir permiso; si no admite imágenes en el portapapeles, usa Subir una imagen. Copiar solo una dirección no copia la imagen: pégala en el campo de enlace.

Sube el brillo desde tu tablet. Pulsa ¡A calcar! para entrar en pantalla completa y bloquear la imagen. Mantén el candado pulsado durante un segundo para volver a ajustar; soltar antes cancela.

El candado bloquea esta interfaz, no los botones ni gestos de Android. Salir de pantalla completa no desbloquea la imagen. El brillo físico depende del dispositivo.

Usa un enlace directo a una imagen, no a una página o red social. Algunos servidores lo impiden: descarga la imagen y súbela como archivo. La interfaz estará disponible offline después de la primera visita; las imágenes remotas pueden necesitar conexión. Las imágenes pegadas o subidas se mantienen solo mientras esta página siga abierta.
